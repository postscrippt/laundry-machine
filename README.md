# LaundryQ MVP Prototype

A dependency-free, mobile-first clickable prototype for shared laundry discovery, queues, bookings, simulated QR check-in, active sessions, notifications, user warnings, and basic administration.

## Run

Open `index.html` in any modern browser. No install or build step is required.

For the primary demo, enter the app, open **University Dorm A**, join its queue, simulate a machine becoming available, claim it, check in, and start the laundry timer.
